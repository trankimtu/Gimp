# Set Resolution

## ⭐ Step 1 — Open your image
Open GIMP → File → Open → choose your logo.

## ⭐ Step 2 — Set the resolution to 96 ppi
This is important because many exports default to 72 ppi.
Go to
```
  Image → Print Size…
```

Set:
```
  X resolution: 96 pixels/in
  Y resolution: 96 pixels/in
  Click OK
```

This does not change pixel size — only the metadata.
